# Kairos 12K Logo Assets

Consistent logo exports for Kairos 12K.

## Primary files

- `kairos-12k-logo.svg` - horizontal logo master.
- `kairos-12k-logo.png` - horizontal logo export.
- `kairos-12k-mark.svg` - square 12K mark master.
- `kairos-12k-mark.png` - 1024px square mark export.

## App files

- `favicon.ico` - browser favicon.
- `app-icon-192.png` - PWA icon.
- `app-icon-512.png` - PWA and maskable icon.
- `app-icon-1024.png` - high-resolution source icon.
- `apple-touch-icon.png` - iOS home-screen icon.

Runtime copies also live in `public/` because the Vite PWA manifest references that folder.
